# SignalSense – Adaptive Traffic Signal Simulation

## Project Overview
SignalSense is a C programming project that simulates an adaptive traffic signal system for four roads: North, South, East, and West.

## Objectives
1. Model vehicle arrivals on four roads.
2. Simulate fixed-time traffic signals.
3. Simulate adaptive green signal timing based on queue length.
4. Calculate queue statistics and estimated average waiting time.
5. Compare fixed-time and adaptive traffic signal performance.

## Technologies Used
- C Programming
- GCC Compiler
- Visual Studio Code

## How It Works
The program accepts vehicle arrival values for four roads and runs two simulations:
- Fixed-time traffic signal simulation
- Adaptive traffic signal simulation

It then displays traffic statistics and compares the results.

## How to Run

Compile:
```bash
gcc signalsense.c -o signalsense
```

Run:
```bash
./signalsense
```
